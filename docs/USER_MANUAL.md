# EMTEES Academy — Quick user manual

Sign in at the website with your username and password. The menu on the left shows only what your role can do.

## Academic Counsellor
1. **Admissions → New registration link.** The link is copied; press the WhatsApp button to send it to the student.
2. The student fills the form and uploads the receipt. The admission moves to *Payment pending verification*.
3. Follow each admission in the list (11 statuses). A rejected payment shows the reason.
4. **Demo classes → Book a demo.** After a completed demo press *Admission link* so the demo teacher's ₹100 bonus can be linked to the admission.

## Accountant
* **Payments:** open the receipt, check it with the bank, press *Verify* (enter the verified amount) or *Reject* (reason required). Nothing can be assigned before this.
* **Teacher pay:** pick the month → open a teacher → *Approve all pending* → *Record payment* (date, method, transaction ID). Corrections are added as separate entries. Download Excel or PDF statements.

## Administrator
* **Admissions:** after verification press *Allocate classes* (you decide the number, duration, session type). Resolve duplicate mobile numbers here.
* **Students:** open a student for balance, history, extend validity (reason required), add or adjust classes (reason required). *Edit* changes course, timing, counsellor, expiry date, password.
* **Staff:** add teachers (English / Hindi / both), counsellors, heads, accountants, admins.
* **Pay rates:** add rules per teacher, course, session type or duration; the most specific rule wins. Defaults are in **Settings**.
* **Settings:** minimum minutes, reconnection window, validity days, default pay, alerts, Google Meet fallback, notifications.
* **Audit log:** every important change with who, when, old value, new value and reason.

## Academic Head
* **Assign teachers:** students with verified payment. Open one, pick a teacher (availability and load are shown).
* **Students → open:** change teacher (reason required — the balance never changes), set the weekly timetable, place on hold.
* **Timetable:** weekly calendar. **Teachers:** workload, availability, approve availability requests. **Requests:** answer student and teacher requests. **Group sessions:** create groups of 2–3 students.

## Teacher
* **Today:** classes sorted by time (now, upcoming, overdue, completed, on hold). *Start class* opens the video room; the class counts automatically.
* If the app video is not usable: **Record Google Meet class** (link, times, who attended, reason).
* **Earnings**, **Availability** (needs head approval), **Requests**, **Demo classes** (accept → start → complete with feedback).

## Student
* **My course:** next class, *Join classroom*, balance, validity, teacher. **Classes:** attendance history. **Requests:** reschedule, teacher change, hold, technical help.

## What counts as a class
Teacher and student must both be connected at the same time for the minimum minutes (set in Settings). A dropped connection that returns within the reconnection window continues the same session.
